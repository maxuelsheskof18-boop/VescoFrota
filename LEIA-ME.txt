VESCO FLEET CONTROL — V4.1 DASHBOARD CORRIGIDO

CORREÇÃO PRINCIPAL
O painel ficava permanentemente em "Atualizando dados..." porque as classes CSS
.login-screen, .admin-layout e .loading-overlay definiam display:grid. Isso podia
sobrescrever o atributo HTML hidden.

A versão 4.1 adiciona:
- [hidden] { display: none !important; }
- timeout de 30 segundos nas chamadas ao Apps Script
- mensagem clara quando a implantação ou URL /exec não responde
- estado inicial explícito para login, painel e overlay
- fallback caso o Chart.js não carregue
- parâmetros ?v=4.1.0 para evitar cache dos arquivos

COMO ATUALIZAR
1. Substitua estes arquivos no front-end:
   - admin.html
   - admin.css
   - admin.js
   - config.js

2. O codigo.gs NÃO precisa ser alterado por causa desta correção visual.
   Ele foi mantido no pacote para facilitar a instalação completa.

3. Reinicie o Live Server.

4. Abra:
   http://127.0.0.1:5500/admin.html

5. Pressione:
   Ctrl + F5

6. Código administrativo padrão:
   VESCO2026

SE A TELA EXIBIR ERRO APÓS 30 SEGUNDOS
- abra config.js;
- confirme a URL terminada em /exec;
- abra a URL /exec diretamente no navegador;
- confirme que o retorno mostra apiVersion 4.0.0-fleet-dashboard;
- no Apps Script, publique uma nova versão da implantação.

ARQUIVOS
- index.html / styles.css / script.js: aplicativo do motorista
- admin.html / admin.css / admin.js: painel administrativo
- config.js: URL da API
- codigo.gs / appsscript.json: back-end Google Apps Script
